requirements
- Need Python
- Network connection

Running - mac os

2 options to run the app
- double click on run.command
- From Terminal - go to folder YOLO App and run command .yolo_app/run.command

For the first time the PC will download relevant libraries and create .venv folder

Running - Windows
1‪.‬ Open cmd in the YOLO app folder
2‪.‬ Install relevant file  (take few minuets)
	python -m venv .venv
	.venv\Scripts\pip install -r requirements.txt

3‪.‬ Open app with command in cmd
	.venv\Scripts\python -m yolo_simple
